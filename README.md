# ClearPay

ClearPay is a responsive multi-page fintech website built using **HTML5, CSS3, and JavaScript**. It is a fictional digital payment platform created as a frontend development demo project.

## About the Project

The website demonstrates modern frontend development concepts including semantic HTML, responsive layouts, CSS design tokens, JavaScript interactions, animations, form validation, and theme switching.

ClearPay is designed to provide a simple and user-friendly experience for businesses that want to manage digital payments and understand transaction activity.

## Pages

The website includes the following pages:

* **Home** – Introduction to ClearPay and its main features.
* **Features** – Displays payment, security, and analytics features with category filtering.
* **Pricing** – Includes a real-time transaction fee calculator.
* **About** – Explains the purpose, mission, and approach of ClearPay.
* **Contact** – Includes a validated contact form.

## Main Features

* Responsive design for mobile, tablet, and desktop screens
* Light and dark theme with localStorage persistence
* Mobile navigation menu
* Real-time pricing calculator
* Filterable features section
* Contact form validation
* IntersectionObserver scroll animations
* FAQ section using semantic HTML
* CSS design token system
* Accessible semantic HTML structure
* Responsive layout from small mobile screens to large desktop screens

## Theme

The website uses a custom green-based color theme:

* Dark Forest – `#102F15`
* Sage – `#728C5A`
* Pale Lime – `#EAF1B1`
* Pastel Mint – `#EBFADC`

The design supports both light and dark modes for a better user experience.

## Testing

The website was tested on different screen sizes including mobile, tablet, and desktop. Navigation, buttons, forms, pricing calculations, feature filters, theme switching, animations, and responsive layouts were checked during development.

Lighthouse was also used to check performance, accessibility, and best practices.
